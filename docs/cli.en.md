# Installation and Usage via CLI (`@bloomui-react/cli`)

🇺🇸 **English Version** | 🇧🇷 [Versão em Português](./cli.md)

Bloom provides a command-line tool (CLI) to automate design system initialization and component installation directly inside your React or Next.js project.

This way, you do not need to clone the base repository or copy code manually — the CLI handles downloading, path translation, and dependency setup.

---

## 🚀 Quick Start

### Step 1: Initialize Bloom in Your Project
At the root of your consumer project, run the command below to configure Bloom:
```bash
npx @bloomui-react/cli init
```
The CLI will open an interactive interface in the terminal asking:
1. **Components Directory**: Where created components should be saved (Default: `components/ui`).
2. **Utilities Directory**: Where support files should be saved (Default: `lib`).
3. **Dependency Installation**: Whether the CLI should automatically install required utility libraries (`clsx`, `tailwind-merge`, and `lucide-react`) in your project.

This command will generate the `bloom.json` file at the root of your project and create the folders and support files:
* `lib/utils.ts` (containing the `cn` utility function for merging classes).
* `lib/design-system.ts` (containing tokens for sizes, semantic colors, and rounded corners).

---

## 🧩 Adding Components

Once the library is initialized, you can add any Bloom component by running:
```bash
npx @bloomui-react/cli add [component-name]
```

**Example:**
```bash
npx @bloomui-react/cli add button
```

### What happens behind the scenes?
1. **Secure Download**: The CLI fetches the original, structured code directly from our official registry.
2. **Dynamic Path Translation**: The script analyzes your project structure (based on `bloom.json`) and rewrites all import references (such as `@/lib/utils` and `@/lib/design-system`) to relative paths corresponding to your local folders.
3. **Dependency Installation**: The system detects the active package manager in your project (`pnpm`, `npm`, `yarn`, or `bun`) and automatically installs any additional Radix UI dependencies, eliminating the manual workflow.
4. **Intelligent AI Documentation**: The CLI extracts full documentation rich with examples, property tables, and real imports, creating a `.md` file at `[utilsDir]/docs/[component].md` to provide full context for AI Coding Assistants (Cursor, Antigravity, Copilot, etc.).

## 🔄 Updating Components

To update all installed components (or a specific one) to the latest version available in the registry:
```bash
# Update all installed components
npx @bloomui-react/cli update

# Update a specific component (e.g. button)
npx @bloomui-react/cli update button
```
This command will overwrite the component's local source code with the latest fixes, install new dependencies if needed, and update the corresponding markdown file in `lib/docs/`.

---

## 🏥 Health Check (`doctor`)

If you encounter issues with import paths or missing files, run the diagnostics:
```bash
npx @bloomui-react/cli doctor
```
It will analyze and validate:
* The existence and validity of the `bloom.json` manifest.
* The physical integrity of component and utility folders.
* The presence of required support files (`utils.ts`, `design-system.ts`, `ripple`).
* The presence of required dependencies (`clsx`, `tailwind-merge`, `lucide-react`) in `package.json`.

---

## 🗑️ Full Uninstallation

If you wish to remove all components, utilities, AI rules, and the manifest generated by Bloom:
```bash
npx @bloomui-react/cli uninstall
```
